## Anomalies connues / points de vigilance

- **Mise en ligne en attente** (crédits Netlify épuisés jusqu'au 8 décembre) : migrations 0014 à 0039 à passer, puis « Compléter depuis les tomes importés » (Administration → Produits) et dépôt du ZIP des bons de commande du Drive, dans
  l'ordre, avec une sauvegarde avant (docs/pilote/PLAN_PILOTE.md).

- TypeScript 7 (nouvelle version native) fait la vérification des types (`npm run typecheck`, paquet `typescript7`, nom
  choisi pour ne pas heurter la dépendance facultative `@typescript/native` de typescript-eslint, qui faisait échouer
  `npm ci` sur GitHub le 19/11/2026) ; TypeScript 6 est installé sous le nom
  `typescript` pour les outils qui en lisent l'API (typescript-eslint, vérification de types de `next build`), comme le
  recommande l'annonce de TypeScript 7. À retirer quand typescript-eslint gérera TypeScript 7.
- ESLint et Prettier configurés le 18/11/2026 ; `lint` et `format:check` font partie des tests GitHub. Le commit de
  formatage est ignoré par `git blame` (`git config blame.ignoreRevsFile .git-blame-ignore-revs`).
- En mode groupé, les lignes non validées restent sur l'appareil (stockage du navigateur) : elles sont
  perdues si l'on vide les données du navigateur avant de valider.
- L'estimation par contenant (« 2 gastros pleins ») n'est pas convertie en kg : il faudrait un poids de
  référence par produit et par contenant.
- La base de développement a été réinitialisée le 06/11/2026 (comptes renommés par fonction) ; elle contient
  une cause de test validée : « Bac oublié en chambre froide ».
- Écran de création de compte : testé par les tests d'intégration, pas encore manuellement dans le navigateur.
- Base de développement : `ALERTES_DEBUT=2026-11-02` dans le `.env` local (test) ; 8 alertes de test pour S45.
- Au premier lancement du serveur de développement, Postgres.app peut demander d'autoriser la connexion :
  tant que ce n'est pas accepté, les pages renvoient une erreur de connexion à la base.
